# 人生選擇器 · Leave it to Fate

選不出來？那就交給命運吧。

[開啟網站](https://hitchhikerbwy.github.io/leave-it-to-fate/)

以派對卡牌遊戲為靈感的日常選擇工具：奶油白桌面、紅黃藍綠四色、黑色粗框與硬陰影。

- **命運輪盤**：自行加入 2～10 個選項，轉出答案。
- **骰子**：擲出一顆六面骰，顯示點數與數字。
- **命運硬幣**：自訂正反面代表的內容，翻出選擇。

## 使用與部署

直接以瀏覽器開啟 `index.html` 即可使用。HTML、CSS、JavaScript、SVG 均包含在此檔案內；不需安裝套件、建置、帳號、後端、資料庫或外部 API。

保留單一靜態檔案的 GitHub Pages 相容性，沿用倉庫現有部署設定。改版以 PR 提交，合併後依既有設定發布。
